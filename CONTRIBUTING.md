# Contributing

Contributions are welcome when they preserve the evidence-first character of the project.

A performance claim must include the hardware topology, exact binary identity, effective arguments, prompt hash, cache state, raw timings, at least one independent cold reload, and a correctness check appropriate to the change. Report failed experiments as well as successful ones. Do not submit model files, credentials, private infrastructure details, or results that cannot be traced to machine-readable evidence.

Run `make verify` before opening a pull request.
