# Security

The repository launches local inference processes and can temporarily change NUMA-related kernel settings when the suite is run with sufficient privileges. Review every generated matrix before execution. Use a loopback-only candidate port, keep production credentials outside the repository, and test restoration before stopping an existing service.

Do not report vulnerabilities by committing secrets or target data. Open a private GitHub security advisory after publication, or contact the maintainer through the address configured on the GitHub profile.
